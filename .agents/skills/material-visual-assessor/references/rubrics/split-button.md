# Split Button

1.  [ID: split_button_edges_spec] Do the leading and trailing buttons have
    straight inner edges and fully rounded outer edges? [Metric type: Hygiene]
    [Weight: 3]

2.  [ID: split_button_trailing_arrow_icon] Does the trailing button feature ONLY
    a downward arrow or dropdown caret icon? [Metric type: Hygiene] [Weight: 3]

3.  [ID: split_button_divider_width] Are the vertical dividing lines between the
    two buttons extremely subtle and thin? [Metric type: Hygiene] [Weight: 1]

4.  [ID: ios_lg_split_button_layer_adherence] On iOS, if a Split Button is
    present, does it enable the Liquid Glass variant when placed on the
    Functional Layer and default to Non-Glass when placed on the Content Layer?
    [Metric type: Adherence] [Weight: 5]
