# Bottom App Bar

1.  [ID: bottom_app_bar_container_shape] Does the bar either stretch full-width
    (docked) or sit as a pill-shaped floating bar? [Metric type: Hygiene]
    [Weight: 3]

2.  [ID: bottom_app_bar_button_target_size] Do action buttons inside the bottom
    app bar appear large enough to touch easily? [Metric type: Hygiene] [Weight:
    3]

3.  [ID: bottom_app_bar_floating_drop_shadow] If a floating bottom app bar is
    present, does it use a drop shadow (or M3 tonal surface elevation; mark
    "N/A" if dark mode or a dark background obscures shadow visibility) to
    elevate it from the background? [Metric type: Hygiene] [Weight: 3]

4.  [ID: bottom_app_bar_simultaneous_nav] Are bottom app bars and bottom
    navigation bars avoided from appearing simultaneously? [Metric type:
    Hygiene] [Weight: 5]
