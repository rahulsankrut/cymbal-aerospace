# Icon Button

1.  [ID: icon_button_usage] Are icon buttons used for common actions in headers,
    cards, or toolbars without requiring text? [Metric type: Hygiene] [Weight:
    3]

2.  [ID: icon_button_default_filled_icons] If non-toggle action icon buttons are
    present, do they use a consistent Material Symbol style (filled or standard
    outlined action icons) across peer controls? [Metric type: Hygiene] [Weight:
    3]

3.  [ID: icon_button_toggle_icon_style] If toggle icon buttons are present, do
    they use an outlined icon when unselected and a filled version when
    selected? [Metric type: Adherence] [Weight: 3]

4.  [ID: ios_lg_icon_button_layer_adherence] On iOS, if Icon Buttons are
    present, does the icon button enable the Liquid Glass variant when placed on
    the Functional Layer (e.g., floating overlays or toolbars) and default to
    Non-Glass when placed on the Content Layer? [Metric type: Adherence]
    [Weight: 5]
