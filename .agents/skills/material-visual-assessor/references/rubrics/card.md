# Card

1.  [ID: card_purpose] Are cards used to display content and actions about a
    single subject in a flexible container? [Metric type: Hygiene] [Weight: 5]

2.  [ID: card_container_rounded_corners] If a Card component (Elevated, Filled,
    or Outlined) is present, does its container comply with the specification:
    corner radius of 12dp (or 16dp for large cards; sys.shape.corner.medium /
    md.sys.shape.corner.medium or sys.shape.corner.large) applied to all four
    corners? [Metric type: Hygiene] [Weight: 10]

3.  [ID: card_text_image_scrim] Is text layered over images only if there is a
    scrim or protection guaranteeing legibility? [Metric type: Hygiene] [Weight:
    5]

4.  [ID: card_elevated_drop_shadow] If an Elevated Card is present, does it use
    a drop shadow (or M3 tonal surface elevation; mark "N/A" if dark mode
    obscures shadow visibility) for elevation? [Metric type: Hygiene] [Weight:
    3]
