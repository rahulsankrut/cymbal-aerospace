# Text Field

1.  [ID: text_field_active_outline_thickness] If a focused/active text field is
    present, does it display a clear, distinct outline or active indicator line?
    [Metric type: Hygiene] [Weight: 3]

2.  [ID: text_field_helper_error_placement] If helper or error supporting text
    is present, is it placed cleanly below the input field container? [Metric
    type: Hygiene] [Weight: 1]

3.  [ID: text_field_error_states_color] If a text field in an error state is
    present, does it utilize a distinct error color role for text and outlines?
    [Metric type: Hygiene] [Weight: 3]
