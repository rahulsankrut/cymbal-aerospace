# Switch

1.  [ID: switch_track_capsule_shape] Is the switch track shaped as a capsule
    with fully rounded ends? [Metric type: Hygiene] [Weight: 3]

2.  [ID: switch_handle_circular] Is the switch handle/thumb circular? [Metric
    type: Hygiene] [Weight: 3]

3.  [ID: switch_no_direct_label] Does the switch stay flat and avoid text labels
    on the component itself? [Metric type: Hygiene] [Weight: 3]

    penalizing for missing Material styling; fail with "No" if incorrectly using
