# Tooltip

1.  [ID: tooltip_usage] Is the tooltip used appropriately for simple
    descriptions (plain) or detailed feature explanations (rich)? [Metric type:
    Hygiene] [Weight: 3]

2.  [ID: tooltip_plain_no_interactive] If a plain tooltip is present, does it
    remain completely non-interactive (no buttons or links)? [Metric type:
    Hygiene] [Weight: 3]

3.  [ID: tooltip_rich_max_buttons] If a rich tooltip is present, does it contain
    a maximum of 2 buttons? [Metric type: Hygiene] [Weight: 3]

4.  [ID: tooltip_obscure_focus_indicators] Do tooltips appear without
    permanently blocking adjacent focus indicators or critical UI? [Metric type:
    Hygiene] [Weight: 3]
