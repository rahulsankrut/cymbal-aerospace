# Suggestion (`<md-gb-suggestion>` & `<md-gb-suggestion-group>`)

The Suggestion component pair (`<md-gb-suggestion>` and `<md-gb-suggestion-group>`) presents post-generation AI prompt replies, conversational follow-up suggestions, and interactive choices generated by AI models.

> **PRIMARY AI RECOVERY RULE**: Do NOT use standard `<md-gb-button>` or `<md-gb-chip>` elements for post-generation AI follow-up suggestions or prompt completions. ALWAYS use `<md-gb-suggestion>` inside `<md-gb-suggestion-group>`.

## Loading Instructions

`<md-gb-suggestion>` and `<md-gb-suggestion-group>` ship in the Google-internal components bundle:

```html
<!-- Google-internal components bundle -->
<script src="https://static.corp.google.com/material-web/gbreeze/latest/components/md-gb-all.js"></script>

<!-- Import icon support -->
<script type="module">
  import '@material/web/labs/gb/styles/icon/md-gb-icon.js';
</script>
```

## API Reference

### `<md-gb-suggestion>` API

| API | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` / `.variant` | `'single' \| 'binary' \| 'multiple-choice'` | `'single'` | Visual layout form. Managed automatically when placed inside `<md-gb-suggestion-group>`. |
| `density` / `.density` | `0 \| -1 \| -2 \| -3 \| -4` | `0` | Vertical density scale (-4px height, -2px top/bottom padding per step). |
| `disabled` / `.disabled` | `boolean` | `false` | Disables interaction and removes element from keyboard tab order. |
| `soft-disabled` / `.softDisabled` | `boolean` | `false` | Disables activation while keeping the suggestion focusable for screen readers (`aria-disabled="true"`). |
| `value` / `.value` | `string` | `''` | Value payload string associated with the suggestion. |
| `aria-label` / `.ariaLabel` | `string` | `undefined` | Accessible label string. Required when label text is brief or ambiguous (e.g. "Yes" or "No"). |

### `<md-gb-suggestion>` Slots and Parts

| Name | Type | Description |
| --- | --- | --- |
| `(default)` | Slot | Visible suggestion label text. |
| `slot="icon"` | Slot | Leading icon element (typically `<md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>`). |
| `part="btn"` | Part | Inner native `<button>` element inside shadow root. |

### `<md-gb-suggestion-group>` API

| API | Type | Default | Description |
| --- | --- | --- | --- |
| `layout` / `.layout` | `'auto' \| 'row' \| 'stack'` | `'auto'` | Responsive layout coordination mode. `auto` adapts based on option count and inline container width. |
| `density` / `.density` | `0 \| -1 \| -2 \| -3 \| -4` | `undefined` | Density scale propagated down to all slotted suggestion children. |
| `heading-level` / `.headingLevel` | `number` | `2` | Heading level (1–6) applied to the internal accessible heading container. |

### `<md-gb-suggestion-group>` Slots

| Slot Name | Description |
| --- | --- |
| `(default)` | Slotted 1–3 `<md-gb-suggestion>` elements. |
| `slot="heading"` | Accessible prompt or question heading element (e.g. `<span slot="heading">Question?</span>`). |

## Adaptive Responsive Layout Matrix

When `layout="auto"` is set on `<md-gb-suggestion-group>`, the group dynamically coordinates layout and child suggestion variants based on child count and container width:

| Option Count | `layout` Mode | Inline Container Width | Group Layout Behavior | Effective Child Variant |
| --- | --- | --- | --- | --- |
| `1` | Any | Any | `single`: Single pill aligned to inline end | `single` (pill) |
| `2` | `auto` \| `row` | Any | `row`: Equal 50/50 horizontal row | `binary` |
| `3` | `auto` | `>= 600px` | `row`: Equal 3-column horizontal row | `binary` |
| `3` | `auto` | `< 600px` | `stack`: Full-width stacked column | `multiple-choice` |
| `>= 3` | `stack` | Any | `stack`: Full-width stacked column | `multiple-choice` |

## Accessibility and Heading Guidance

- **Phrasing Text for Headings**: Always pass phrasing text (e.g. `<span slot="heading">Question?</span>`) inside `slot="heading"`. Do NOT pass nested heading elements (`<h1>`-`<h6>`) or unescaped raw text nodes.
- **Ambiguous Labels**: Provide explicit `aria-label` strings for brief choices (e.g., `aria-label="Yes, apply suggested edits to document"`).

## Usage Examples

### Single Suggestion Pill

```html
<md-gb-suggestion-group>
  <span slot="heading">Would you like to draft a follow-up response?</span>
  <md-gb-suggestion>
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Draft response
  </md-gb-suggestion>
</md-gb-suggestion-group>
```

### Binary Suggestion Row (50/50 Layout)

```html
<md-gb-suggestion-group>
  <span slot="heading">Apply suggested edits to document?</span>
  <md-gb-suggestion aria-label="Yes, apply changes to current draft">
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Yes, apply
  </md-gb-suggestion>
  <md-gb-suggestion aria-label="No, discard changes and keep original">
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    No, discard
  </md-gb-suggestion>
</md-gb-suggestion-group>
```

### Multiple Choice Adaptive Group

```html
<md-gb-suggestion-group>
  <span slot="heading">Select summary depth</span>
  <md-gb-suggestion>
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Bullet-point overview
  </md-gb-suggestion>
  <md-gb-suggestion>
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Executive summary
  </md-gb-suggestion>
  <md-gb-suggestion>
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Detailed breakdown
  </md-gb-suggestion>
</md-gb-suggestion-group>
```

### Soft-Disabled State Example

```html
<md-gb-suggestion-group>
  <span slot="heading">Export options</span>
  <md-gb-suggestion>
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Export as Markdown
  </md-gb-suggestion>
  <md-gb-suggestion soft-disabled aria-label="Export as PDF (Generation in progress)">
    <md-gb-icon slot="icon">prompt_suggestion</md-gb-icon>
    Export as PDF
  </md-gb-suggestion>
</md-gb-suggestion-group>
```
